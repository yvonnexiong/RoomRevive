A splat is a floater if it has few neighbours in a 3×3×3 voxel block around it — i.e. it floats in empty space, not on a dense surface. Max density = the neighbour count below which a splat counts as a floater (raise to catch more, lower to flag only the most isolated). Neighbourhood = voxel size.

Method

Real Boxer (facebookresearch/boxer): render the splat from 40 posed views → OWLv2 open-vocab 2D detection of "refrigerator" → BoxerNet (DINOv3 + camera + the splat point cloud as semi-dense depth) lifts each to a 3D oriented box → multi-view fusion. Splat +Y-up is rotated to Boxer's +Z-up gravity frame and the result rotated back.
