# Product Overview

## Problem
Users cannot visualize how a showroom kitchen fits their real space.

## Solution
RoomRevive reconstructs the user’s room and applies lifestyle-based transformations.

## Key Innovation
Not different kitchens  
→ Different lives in the same kitchen

## Experience Flow

1. User sees their real kitchen
2. Chooses an intent
3. Kitchen transforms instantly
4. User explores products via hotspots

## Success Criteria
- User recognizes their own space
- Clear emotional difference between intents
- Product discovery feels natural, not sales-driven
